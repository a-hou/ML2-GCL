## 🚀 Cómo ejecutar

Asegúrese de tener instalados el entorno de Python y las librerías requeridas. Todas las dependencias necesarias se encuentran listadas en el archivo `requirements.txt`.

Luego, ejecute el script principal utilizando el siguiente comando:

```bash
python main.py
```
